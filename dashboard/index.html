How the value is worked out

One formula, the same for every protocol. No protocol name is ever special-cased.

  1. Category multiple. From the protocols that record a token, take the median market-cap-to-TVL ratio inside the protocol's own category. A category counts only with at least 3 tokened peers; otherwise the protocol uses the global median across all tokened protocols. The multiple is clamped to 0.02–2.00 so one outlier token cannot set the price of a whole category.
  2. Base value = TVL × category multiple.
  3. Growth. The protocol's 7-day TVL change, clamped to −50%…+100%, moves the value by 1 + change × 0.4. Growth raises it, decline lowers it, and the effect is bounded.
  4. Longevity. From the day DefiLlama began tracking the protocol: 1 + min(age in years, 5) × 0.04. A protocol that has run for years with no token yet has proven staying power, so it earns a modest bonus; an unknown listing date earns none.
  5. Implied value = base × growth × longevity, rounded to whole dollars.
